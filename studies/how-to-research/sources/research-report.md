# How to Research — Synthesis Note + Source List

## Synthesis note (how the pieces fit)

The eight requested sections collapse into one through-line: **a claim earns its place in a study only after it survives a pipeline — well-formed question → evaluated source → independent corroboration → disconfirmation attempt → calibrated confidence → traceable citation.** Each canonical framework owns one stage of that pipeline:

- **Question stage** — FINER (appraise) + PICO (decompose). The non-obvious finding: FINER's "Novel" and PICO's "Comparator" are the two most-skipped elements, and skipping them is what produces unanswerable or redundant questions. Background-vs-foreground typing prevents over-investing on definitional questions.
- **Source stage** — SIFT decisively beats CRAAP because CRAAP evaluates a page *from inside the page*, checking exactly the features a bad source fakes most easily; SIFT's lateral reading leaves the page. Primary>secondary is a heuristic that **inverts at the top of the evidence pyramid** (a good meta-analysis outranks any single primary study because it already triangulated) — this nuance matters and is easy to get wrong.
- **Corroboration stage** — triangulation (Denzin's four types) generalizes the repo's "2+ domains" rule. The load-bearing subtlety the repo currently misses: **independence**. Two sources copied from a common origin are one source; convergence among echoes adds zero validity. SIFT's "Trace claims" is the tool that detects shared origin.
- **Search/stop stage** — exploratory (broad→narrow, R3 default) vs systematic (PRISMA, reproducible). Saturation (new searches return only already-seen sources) is a *completeness* stopping rule that complements R3's *cost* budget; use whichever fires first and record it.
- **Synthesis stage** — Zettelkasten's layered capture enforces "citation attached at capture," and the synthesis matrix operationalizes triangulation as a worksheet whose core rule ("a trend needs ≥2 sources") is identical to the corroboration rule. The repo gap here is failing to separate claim / evidence / **inference**.
- **Calibration stage** — Tetlock/Brier: stated confidence must match hit rate, and *resolution* (decisiveness when warranted) is as important as calibration — which argues against the repo's likely tendency to default everything to "Medium."
- **Bias/integrity stage** — confirmation bias is the default failure and *worsens with confidence*; the four concrete countermeasures (seek disconfirming evidence, steelman, Platt strong inference with multiple hypotheses, accountability) converge on one missing repo step: **a deliberate attempt to break your own conclusion.** This is the single highest-value addition identified.
- **Provenance stage** — the repo's dated-citation standard is the floor; PRISMA-S argues for recording the *queries* too, so a study is re-runnable, not just trusted.

**Contradiction flagged:** "prefer primary over secondary" (general-research advice) vs. the EBP pyramid placing systematic reviews/meta-analyses *above* primary RCTs. Resolution: both hold at different scopes — prefer primary over *interpretive* secondary summaries, but a rigorous synthesis that has itself triangulated outranks a lone primary study. README states this explicitly rather than picking one.

**Domain-transfer caveat (unverified for our domains):** the evidence hierarchy is medical-EBP-specific; its transfer to fiction-craft / legislation / game-data research is asserted by analogy, not sourced. Listed as a known gap + next step.
