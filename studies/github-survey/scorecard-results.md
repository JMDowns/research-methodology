## 1. Scoring Protocol & Evidence Tags

Every repository below was scored by inspecting its committed source files, agent/skill prompts, evaluation scripts, sample outputs, and open/closed GitHub Issues via `gh api` ([`sources/a-apps-and-frameworks.md`](sources/a-apps-and-frameworks.md), [`sources/b-skills-and-written-methods.md`](sources/b-skills-and-written-methods.md), [`sources/c-scientific-and-benchmark-agents.md`](sources/c-scientific-and-benchmark-agents.md)).

Per [`../how-to-measure/SCORECARD.md`](../how-to-measure/SCORECARD.md), scores are never averaged across tiers into a single 1D number, and every cell is explicitly tagged with its **Evidence Type**:
- **`[Desk-Only]`**: Verified directly from repository source code, prompts, and git file tree (`D1–D8`).
- **`[Measured-Self]`**: Quantitative quality (`O1–O6`) or run cost/consistency (`R1–R6`) reported by the repository's own authors in their repo or accompanying paper.
- **`[Measured-Independent]`**: Quantitative quality, reproduction, or failure audit reported by an independent third party (external benchmark paper, independent reproduction issue, or our own controlled experiments on an external skill).

### Kill / Pivot Criterion Check
The proposal ([`01-github-research-methods-survey-2026-11-09.md`](../research_proposals/01-github-research-methods-survey-2026-11-09.md)) specified: *"If fewer than 5 of the 20 in-depth repos publish any outputs or evaluation, drop the numeric scoring and deliver a design comparison only."*
- **Outcome: Did NOT fire.** Among the 24 external in-depth repositories, **9 commit full sample outputs (`D7 = 1`)** and **14 publish quantitative evaluation numbers in-repo or in their accompanying paper** (far exceeding the $\ge 5$ threshold). However, **only 3 of 24 external repos (`12.5%`) pass `D8 = 1`** by committing both evaluation scripts/results AND explicit per-run token or dollar cost figures inside the repository (`assafelovic/gpt-researcher`, `langchain-ai/open_deep_research`, and `SakanaAI/AI-Scientist`).

## 2. Tier A Desk Scorecard (`D1–D8`) Across 24 External Repos + Ours

**Binary Desk Items (`1` = Yes in default workflow, `0` = No):**
- **D1:** Upfront Question Decomposition / Planning

- **D3:** Explicit Search / Turn / Token Budget Cap ($\le 100$ calls or $\le 10$ depth rounds; note: `MiroThinker` uses a 300-turn cap and scores `0` under the strict $\le 100$ gate)

### Key Desk Scorecard Patterns Across the 4 Buckets

1. **Type B (Written Methods & Hybrid Skills) are our closest structural peers — averaging `6.3 / 8` on Tier A Desk items** vs. `4.9 / 8` for Type A apps, `5.2 / 8` for Type C scientific agents, and `3.3 / 8` for Type D benchmark agents. All 7 scored Type B repos enforce explicit verification (`D4 = 1`), explicit uncertainty/gap handling (`D5 = 1`), and persistent intermediate artifacts (`D6 = 1`).
2. **Abstention & Uncertainty Honesty (`D5`) is the sharpest divider between Type A/D and Type B/C:** Only **1 of 7** Type A apps (`AnotiaWang/deep-research-web-ui`, which tracks `confidence` and `conflictsWith` per learning) and **0 of 4** Type D benchmark agents pass `D5`. By contrast, **7 of 7** Type B repos and **4 of 6** Type C repos pass `D5`.
3. **Cost & Evaluation Transparency (`D8`) is the rarest practice in open-source research:** Only **3 of 24** external repos (`assafelovic/gpt-researcher`, `langchain-ai/open_deep_research`, and `SakanaAI/AI-Scientist`) commit both quantitative evaluation results and explicit token/dollar cost figures in their repo.

## 4. Verdict on the Proposal's Disconfirmer

- **Disconfirmer stated in proposal (`01-github-research-methods-survey-2026-11-09.md`):** *"At least 3 repos with independently measured faithfulness at or above our fact-check results, at lower cost. Our measured change rate of about 7.7% per fact-check [92.3% pre-check accuracy; 94% Arm A full entailment] is the comparison point."*
- **Outcome: Disconfirmer did NOT fire (0 repos met all three conditions).**
  1. **Zero external repositories have `[Measured-Independent]` long-form claim entailment $\ge 92.3\%$ at lower cost.** In fact, independent measurements consistently revealed *lower* faithfulness or reproduction scores than self-reports: our independent test of the shipped `deep-research` skill (`Arm B`) found **74% full claim entailment** (`26%` drift); `Imbad0202`'s post-publication audit found **30.9% (`21/68`) reference defects** surviving 3 internal LLM check rounds prior to API gating; and `AI-Scientist-v2`'s independent audit (`osf.io/aqchj`) found **0/24 papers underwent VLM verification**.
  2. Even on `[Measured-Self]` numbers, the only repositories reporting $>90\%$ claim/citation accuracy either evaluate short conversational turns (`stanford-oval/WikiChat` at **97.3%**, without published cost), evaluate single-question scientific QA with **21.9% abstention** (`Future-House/paper-qa` at **85.2% LitQA2 precision**), or evaluate a 1-query run without cost telemetry (`AnkitClassicVision` V4 at **100% (`8/8`) citation audit pass**, `cost: n/a`).
