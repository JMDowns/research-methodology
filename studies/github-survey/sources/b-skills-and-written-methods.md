# Type B Survey: Skills, Prompt Packs, Written Methodologies & Persistent Wiki Research Repos

## Executive Summary

- **Q0 Discovery Probe Verdict — Passed Decisively (35+ real Type B repos found):** While multi-word quoted phrase searches on `gh search repos` fail when syntax operators (`OR`, `filename:`) are enclosed inside a single quoted string, passing separate keyword tokens (`gh search repos deep research skill`, `gh search repos "claude code" "deep research"`, `gh search repos "llm wiki" research`, `gh search code "deep-research" --filename SKILL.md`) surfaced **35+ genuine Type B repositories**, refuting the proposal's riskiest assumption (<10 candidates).
- **Taxonomy of Type B Methods:** Type B repositories divide cleanly into three architectural sub-families:
  1. **B1 — Hybrid Code + Skill Harnesses** (`jordan-gibbs/hyperresearch` [4,453★], `199-biotechnologies/claude-deep-research-skill` [1,212★], `lingzhi227/agent-research-skills` [459★], `fivetaku/insane-research` [292★], `azagreev/DResearch-Skill` [0★]): Markdown skills paired with deterministic Python CLIs for SQLite FTS quote checking, Crossref/OpenAlex retraction checking, MinHash source-independence clustering, OA full-text rescue, and JSONL ledger validation.
  2. **B2 — Written Multi-Agent Prompt Pipelines & Epistemic Contracts** (`Imbad0202/academic-research-skills` [56,172★] & forks `xrb936`/`Clebeep`, `Weizhena/Deep-Research-skills` [2,517★], `AnkitClassicVision/Claude-Code-Deep-Research` V4 [147★], `oh-rid/deep-research` [40★], `tonyazhuuki/deep-research-skill` [32★], plus our local shipped Anthropic `deep-research` skill): Pure or lightly scripted Markdown agent systems that solve sycophancy, frame-lock, premature convergence, and writer drift via structural protocols (paper-blind Sprint Contracts, Devil's Advocate concession thresholds, multi-LLM CLI triangulation, and entity-attribute JSON matrix generation).
  3. **B3 — Persistent LLM Research Wikis (Karpathy `llm-wiki` Pattern)** (`SamurAIGPT/llm-wiki-agent` [3,686★], `PKU-DAIR/AutoSci` [1,729★], `nvk/llm-wiki` [1,521★], `iamsashank09/llm-wiki-kit` [63★], `MetamusicX/zissa-wiki` [62★], `KevinYoung-Kw/robust-llm-wiki` [10★]): Vault architectures (`raw/` immutable sources → `wiki/` LLM-maintained interlinked pages → `schema/` governance) using an `ingest → query → lint` loop rather than stateless report generation.
- **Highest-Leverage Mechanisms Missing from Our Current `~/dev/research/` System:**
  1. **Patch, Never Regenerate (`[Read, Edit]`-locked post-synthesis agents):** Both `jordan-gibbs/hyperresearch` (Steps 14–16) and `azagreev/DResearch-Skill` (Phase 5) forbid post-draft critique/polish agents from calling `Write` or regenerating the report; they are tool-locked to `[Read, Edit]` with per-hunk size caps. This directly eliminates the **separate-writer claim drift** we measured in [`research-pipeline-hybrid-comparison/README.md`](file:///home/jonathan/dev/research/research-pipeline-hybrid-comparison/README.md) (`400_at_80pct` → "at least 400").
  2. **Mechanical Quote-Integrity + Source-Independence Clustering (`hyperresearch` & `zissa-wiki`):** Verifying every verbatim quote (≥5 words in `hyperresearch`; all quotes + printed PDF pages in `zissa-wiki`) deterministically against cached source notes via SQLite FTS/Python before ship, and collapsing syndicated copies of the same press release/wire story into a single independent vote via MinHash + canonical URL + dateline clustering.
  3. **Paper-Blind Sprint Contracts & Devil's Advocate Concession Thresholds (`Imbad0202` / `xrb936` / `Clebeep`):** A two-call gate where evaluators commit to falsifiable evaluation triggers (`<phase1_output>` / `<phase4a_output>`) *before* reading the draft/paper, paired with a 1–5 rebuttal scoring rubric (concede only on ≥4) that reduced citation/frame-lock errors from 31% in v2.7 stress testing.
  4. **Step-per-Skill Lazy Loading (`hyperresearch`):** Loading each pipeline stage as a separate skill file (`hyperresearch-step-01` … `step-16`) only when reached, preventing long-horizon context rot from silently dropping late verification steps.
  5. **Consequence-Tiered Subquestions + Signed Residue Statements (`AnkitClassicVision` V4) & Two-Axis + Frontier Radar Grading (`tonyazhuuki`):** Tagging subquestions `context` (0.60) / `finding` (0.80) / `decision` (0.92, requiring cross-model verification + live re-fetch), separating evidence strength from forward-looking *promise* (with a mandatory *Resolving event*), and requiring a signed `residue_statement.md` enumerating unresolved questions.

### 3.1 [`jordan-gibbs/hyperresearch`](https://github.com/jordan-gibbs/hyperresearch) — Hybrid 16-Step Lazy-Loaded Pipeline + Persistent FTS Vault

- **Stars / Activity:** 4,453 stars, actively maintained (updated 2026-04-20, v6.2+) ([repo metadata](https://github.com/jordan-gibbs/hyperresearch) — accessed 2026-11-09).
- **Inspected Primary Files:** [`README.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/README.md) — accessed 2026-11-09, [`skills/hyperresearch/SKILL.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/skills/hyperresearch/SKILL.md) — accessed 2026-11-09, [`skills/hyperresearch-verify/SKILL.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/skills/hyperresearch-verify/SKILL.md) — accessed 2026-11-09, and [`codex_bench/README.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/codex_bench/README.md) — accessed 2026-11-09.

#### Pipeline Phases, Prompts & HITL Checkpoints
`hyperresearch` runs a tier-adaptive pipeline (`light` = 5 steps: `1, 5, 7, 11, 12`; `full` = 16 steps + `14.5` cite-check; `dissertation` = chaptered monograph loop scaling to 25k–80k words) ([`skills/hyperresearch/SKILL.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/skills/hyperresearch/SKILL.md) — accessed 2026-11-09):
1. **Step-per-skill lazy loading:** Instead of putting all 16 stages into one giant `SKILL.md` (which causes late-stage instructions to drop out of attention as context fills), the root `SKILL.md` is a thin dispatcher that loads `hyperresearch-step-01` through `hyperresearch-step-16` one at a time via the `Skill` tool ([`README.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/README.md) — accessed 2026-11-09).
2. **16-Step Sequence (`full` tier):**
   - **Step 1 Triage & Frame:** Classify query type (`factual`, `comparative`, `exploratory`, `evaluative`, `current-events`, ` investigative`, `academic`), tier, and temporal freshness.
   - **Step 2 Check Existing Vault:** Run `hyperresearch search "<topic>"` (SQLite FTS5) over `research/` before hitting the web.
   - **Step 3 Plan & Clarify (Adaptive HITL):** Ask 1–2 clarifying questions *only* when query is <8 words and spans ≥2 incompatible domains; otherwise auto-proceed (`--yes` skips).
   - **Step 4 Scout:** Parallel surface-area mapping across domains.
   - **Step 5 Search & Fetch:** Execute `hyperresearch fetch` with automatic OA rescue (Unpaywall → Europe PMC JATS XML → CORE) whenever a scientific page is <6,000 chars or HTTP 403.
   - **Step 6 Extract Notes:** Atomic source notes saved to `research/notes/<slug>.md` with YAML frontmatter (`type: source`, `url`, `date`, `quality: high|medium|low`, `independence_group_id`) and `[[wikilinks]]`.
   - **Step 7 Evidence Table:** Build `_evidence.md` mapping claims to supporting/contradicting sources and independence cluster counts.
   - **Step 8 Corpus Critic (Pre-Synthesis Adversarial Gate):** Inspects `_evidence.md` *before* drafting to ask: *"What source would overturn this? What is thin, circular, or time-stale?"* Runs a mandatory **Gap-Fill Pass** (Steps 5–6) before synthesis is allowed to start.
   - **Step 9 Plan Outline:** Locks report structure and section word/citation budgets.
   - **Step 10 Deep Read:** Re-reads full primary source notes for high-consequence sections.
   - **Step 11 Synthesize Report:** Drafts `research/reports/<slug>.md` directly from `_evidence.md` and `research/notes/`.
   - **Step 12 Verify & Cite-Audit + Step 14.5 Cite-Check:** Runs Python mechanical triage + `hyperresearch-cite-checker` (`model: sonnet`, `[Read, Grep, Glob]` only) to match every claim to a fetched note.
   - **Step 13 Self-Critique:** Runs `hyperresearch-critic` (`model: opus`) and `hyperresearch-instruction-critic` (`model: sonnet`) producing `_critique.md` and `_instruction_audit.md`.
   - **Step 14 Patcher (`[Read, Edit]` only), Step 15 Polish (`[Read, Edit]` only), Step 16 Readability (`[Read, Edit]` only):** Applies surgical edits from `_critique.md` and `_cite_audit.md`. **No post-synthesis agent has the `Write` tool.**
   - **Final Mechanical Ship Gate:** `hyperresearch run verify --workspace <ws> --json` checks all hard invariants and stamps `.shipped.json`. In Codex, a `.codex/hooks.json` `Stop` hook invokes `hyperresearch run stop-gate` to block session termination if `.shipped.json` is missing ([`codex_bench/README.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/codex_bench/README.md) — accessed 2026-11-09).

#### Claim Verification, Fact-Checking & Confidence/Evidence Grading
`hyperresearch` combines four deterministic verification mechanisms with two LLM audit passes ([`README.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/README.md) — accessed 2026-11-09; [`skills/hyperresearch-verify/SKILL.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/skills/hyperresearch-verify/SKILL.md) — accessed 2026-11-09):
1. **Mechanical Quote-Integrity Gate:** Every verbatim quotation ≥5 words in the report is extracted and verified via SQLite FTS / substring matching against the cited `research/notes/<slug>.md` body. Paraphrases put inside quotation marks fail the build.
2. **Numeric Consistency Gate:** Every number/percentage/currency figure in the executive summary and tables is cross-checked against body prose and cited source notes.
3. **Source-Independence Clustering (Anti-Syndication Gate):** Computes MinHash similarity + wire-service dateline detection + canonical URL resolution across all fetched notes. Five articles reprinting the same Reuters wire or PR Newswire release receive a single `independence_group_id` and count as **1 vote, not 5** when computing multi-source corroboration.
4. **Live Retraction Check at Ship Time:** Queries Crossref (`update-to` metadata) and OpenAlex (`is_retracted`) for every cited DOI; retracted papers fail the ship gate unless explicitly framed as retracted in prose.
5. **OA Rescue Provenance Banners:** When a paywalled article is rescued via Unpaywall/Europe PMC/CORE (`oa_recovery_kind: rescued`) or falls back to abstract-only (`body_is_not_from_source: true`), the note frontmatter and body carry an explicit machine-readable banner forbidding the synthesizer from quoting text that was not in the full text.
6. **Prompt Injection Isolation:** Every fetched webpage is truncated first and then wrapped in `<untrusted-source url="...">...</untrusted-source>` delimiters so truncation never cuts off the closing tag.

#### Storage, Indexing, Deduplication & Reuse
- Uses a persistent local Markdown vault (`research/notes/`, `research/reports/`, `research/moc/` Maps of Content, `research/workspaces/`) indexed by a zero-config SQLite FTS5 index (`hyperresearch search`, `hyperresearch index`, `hyperresearch lint`, `hyperresearch graph`, `hyperresearch stats`) ([`README.md`](https://raw.githubusercontent.com/jordan-gibbs/hyperresearch/main/README.md) — accessed 2026-11-09).
- Every note is an Obsidian-compatible Markdown file with `[[wikilinks]]`. Step 2 queries this vault before any web search so prior research compounds across sessions.

#### Three Structural LLM Failure Modes Identified & Their Protocol Fixes
In [`docs/POSITIONING.md`](https://raw.githubusercontent.com/xrb936/academic-research-skills-claude/main/docs/POSITIONING.md) — accessed 2026-11-09, the authors document three structural failure modes discovered during v2.7–v3.0 testing and their architectural countermeasures:
1. **Failure Mode 1 — Frame-Lock (31% citation error rate in v2.7 stress test):** When the same agent (or an evaluator reading the draft first) generates and verifies claims, it shares the generator's cognitive frame and rationalizes defects.
   - **Fix A — Paper-Blind Sprint Contracts (Schema 13 / 13.1 / 13.2):** Introduced in v3.6.2–v3.6.6 ([`academic-paper-reviewer/SKILL.md`](https://raw.githubusercontent.com/xrb936/academic-research-skills-claude/main/academic-paper-reviewer/SKILL.md) — accessed 2026-11-09). Review and drafting evaluation are split into a **two-call hard gate**: in **Phase 1 (Paper-Blind)**, the agent receives *only* the venue/domain, research type, and title/topic (never the manuscript or abstract) and must emit `<phase1_output>` containing 3–7 falsifiable `pass_criteria` and `rejection_triggers`. Only after `<phase1_output>` is persisted can **Phase 2 (Paper-Visible Evaluation)** read the manuscript and bind every Major/Critical finding to a pre-registered `trigger_id` (`T1..TN`).
   - **Fix B — Context Reset Boundaries:** Logged in `passport.yaml` (`reset_boundary[]` with `artifact_hash` SHA-256) between drafting and review so the reviewer starts with zero shared conversation history ([`docs/ARCHITECTURE.md`](https://raw.githubusercontent.com/Imbad0202/academic-research-skills/main/docs/ARCHITECTURE.md) — accessed 2026-11-09).
2. **Failure Mode 2 — Sycophancy Under Pushback:** Critique agents immediately capitulate when the lead agent pushes back.
   - **Fix — Devil's Advocate Concession Threshold Protocol:** The Devil's Advocate agent (`Agent 7` in `deep-research`, `Agent 4` in `academic-paper`) scores every rebuttal on a **1–5 scale** (`1` = assertion without evidence, `3` = plausible logic without source verification, `4` = verified counter-evidence from primary source, `5` = decisive methodological refutation) and is **forbidden from conceding on scores < 4** ([`docs/POSITIONING.md`](https://raw.githubusercontent.com/xrb936/academic-research-skills-claude/main/docs/POSITIONING.md) — accessed 2026-11-09).
3. **Failure Mode 3 — Parametric Memory Leakage & AI Research Shortcuts:**
   - **Fix A — Anti-Leakage Protocol (adapted from PaperOrchestra, arXiv:2604.05018):** Enforces 4 hard rules during writing: (1) No backward engineering from conclusions, (2) No parametric completion of missing specs (must insert `[MATERIAL GAP: <missing parameter>]` instead of guessing hyperparameters or dataset splits), (3) Strict input isolation per section, and (4) Claim-to-source traceability tags (`[SOURCE: Table 2]`, `[SOURCE: BibTeX#key]`) ([`academic-paper/protocols/Anti_Leakage_Protocol.md`](https://raw.githubusercontent.com/xrb936/academic-research-skills-claude/main/academic-paper/protocols/Anti_Leakage_Protocol.md) — accessed 2026-11-09).
   - **Fix B — Stage 2.5 & 4.5 Mandatory Integrity Gates (`ai_research_failure_modes.md`):** Operationalizes the **7-mode taxonomy from Lu et al. (2026, *Nature*, `10.1038/s41586-026-10265-5`, "The AI Scientist")**: `M1` implementation bug passing self-review, `M2` hallucinated citation (checked via Semantic Scholar API with normalized Levenshtein title similarity ≥0.70 + author overlap + year ±1), `M3` hallucinated experimental result, `M4` shortcut reliance, `M5` bug reframed as novel insight, `M6` methodology fabrication, and `M7` early frame-lock ([`academic-pipeline/references/ai_research_failure_modes.md`](https://raw.githubusercontent.com/Imbad0202/academic-research-skills/main/academic-pipeline/references/ai_research_failure_modes.md) — accessed 2026-11-09).
4. **Fork Contribution (`Clebeep/academic-research-skills-claude-science-fixed` / Issue #214) — Sub-Claim Decomposition in Editorial Synthesis:**
   - Standard multi-reviewer aggregation operates at the "bundle level" (if 2 of 3 reviewers like a section, a 3rd reviewer's discovery of a fatal statistical flaw gets downweighted as a minority opinion). `Clebeep` adds [`subclaim_extraction_schema.md`](https://raw.githubusercontent.com/Clebeep/academic-research-skills-claude-science-fixed/main/academic-paper-reviewer/references/subclaim_extraction_schema.md) — accessed 2026-11-09, decomposing every reviewer comment into atomic triples `(target_section, claim_type, polarity)` with a **Minority Critical Preservation Rule**: any `negative_critical` sub-claim with specific textual evidence (`e.g., Eq. 4, Table 2`) cannot be overridden by positive `general` votes from other reviewers.

- **Key Mechanisms:**
  1. **3-Cycle Adversarial Ensemble:** Cycle 1 spawns 3–5 `SCOUT` agents with distinct cognitive styles (` empiricist`, `mechanist`, `skeptic`, `historian`, `practitioner`); Cycle 2 spawns `CRITIC` + `METHODOLOGIST` in parallel (tagging claims `ROBUST`, `CONTESTED`, `WEAK`, `UNSUPPORTED`); Cycle 3 dispatches `DEEP DIVER` agents specifically on `CONTESTED` claims (<0.5 confidence) before `SYNTHESIZER` + `FRONTIER_ANALYST` + `FACT-CHECKER` run.
  2. **Two-Axis Evidence Appraisal ("Design First, but N Bounds the Claim"):** Grades every empirical study on **Axis 1 (Causal Design / Bradford-Hill criteria)** and **Axis 2 (Sample Size / External Validity)**. A rigorous N=8 RCT can establish a narrow causal mechanism (`Axis 1 High`), but its generalization is strictly bounded by `Axis 2 Low`.
  3. **Frontier Radar (Separating Evidence Strength from Promise):** Standard GRADE rubrics penalize novel breakthroughs because early studies have small N. `tonyazhuuki` adds a separate **Frontier Radar** section for low-GRADE / high-mechanistic-plausibility findings, requiring every entry to specify a concrete **Resolving event** (e.g., *"Phase II NCT05... readout expected Q4 2026 or independent replication on ≥500 tasks"*).
  4. **Decisions Ledger + Read-Back Test:** Logs every scope exclusion or contradictory-source tie-break in a `Decisions Ledger` and runs a `Read-Back Test` verifying that a reader who reads *only* the executive summary cannot walk away with a stronger claim than the body supports.

#### C. [`oh-rid/deep-research`](https://github.com/oh-rid/deep-research) (40★) — Cross-Model Family Triangulation + Shared-Imagination Defense
- **Inspected Files:** [`README.md`](https://raw.githubusercontent.com/oh-rid/deep-research/main/README.md) — accessed 2026-11-09 and [`commands/deep-research.md`](https://raw.githubusercontent.com/oh-rid/deep-research/main/commands/deep-research.md) — accessed 2026-11-09.
- **Key Mechanisms:**
  1. **Cross-Family CLI Triangulation:** Runs the same research query across three model families in parallel: **Claude** (lead session), **Gemini 3.1 Pro** (`agy --sandbox`), and **GPT-5** (`codex -s read-only`), with a strict **Anti-Anchoring Rule** requiring Claude to write its own initial findings *before* reading the Gemini and Codex outputs.
  2. **Rule D — "Evidence Weight > Vote Count" (Grounded in *Shared Imagination*, arXiv:2407.16604):** Explicitly warns that LLMs trained on overlapping web corpora share correlated blind spots and hallucinations. Therefore, **3/3 model agreement without a verified primary URL is tagged `[Consensus-only — elevated hallucination risk]`**, whereas **1/3 model claim backed by a verified primary URL overrides 2/3 unverified model consensus**.
  3. **Rule B (Empirical CLI Flag Check):** Any claim about a CLI flag or tool option must be verified via `<cmd> --help` on disk if installed.

## 5. Failure Modes Solved Across Type B & Actionable Recommendations for `~/dev/research/`

### 5.1 Catalogue of Failure Modes Documented and Solved in Type B Repos

1. **Post-Draft Rewrite Drift (Separate Writer / Polisher Hallucination):**
   - *Where observed:* Our own Arm D experiment ([`research-pipeline-hybrid-comparison/README.md`](file:///home/jonathan/dev/research/research-pipeline-hybrid-comparison/README.md)), `jordan-gibbs/hyperresearch`, `azagreev/DResearch-Skill`, `Weizhena/Deep-Research-skills`.
   - *Mechanism of failure:* Giving a critique, polish, or report-writer agent the `Write` tool causes it to regenerate prose from working memory, smoothing away hedges (`400_at_80pct` → `"at least 400"`) or dropping citations.
   - *Proven fixes:* (a) **Tool-lock post-synthesis agents to `[Read, Edit]`** with per-hunk size caps (`hyperresearch` Steps 14–16, `DResearch-Skill` Phase 5); (b) for structured entity comparisons, use a **deterministic Python compiler** (`Weizhena` `/research-report`) from validated JSON/YAML to Markdown.
2. **Long-Horizon Context Rot Dropping Late Verification Steps:**
   - *Where observed:* `jordan-gibbs/hyperresearch`, `lingzhi227/agent-research-skills`.
   - *Mechanism of failure:* When a 10–16 step workflow is loaded in a single monolithic prompt, context accumulation during search/fetch pushes steps 12–16 (verification, critique, citation check) out of effective attention, causing the agent to jump straight from search to final report.
   - *Proven fixes:* (a) **Step-per-skill lazy loading** (`hyperresearch`), loading each stage's prompt only when reached; (b) **file-existence phase gates** (`lingzhi227`) or **Stop-hook ship gates** (`hyperresearch run stop-gate`, `zissa-wiki` `.claude/hooks/lint_gate.py`).
3. **Syndicated Echo Chambers (Counting 5 Wire Reprints as 5 Independent Sources):**
   - *Where observed:* `jordan-gibbs/hyperresearch`, `azagreev/DResearch-Skill`, `AnkitClassicVision` V4, `oh-rid/deep-research`.
   - *Mechanism of failure:* "Triangulating across ≥3 sources" fails when all 3 URLs reprint the same press release, benchmark blog post, or shared LLM pretraining myth (*Shared Imagination*, arXiv:2407.16604).
   - *Proven fixes:* (a) **Source-independence clustering** (MinHash/3-gram Jaccard + canonical URL + wire dateline in `hyperresearch` / `DResearch-Skill`); (b) **Branch disjointness gate** (`>30%` shared sources merges branches in `AnkitClassicVision` V4); (c) **Rule D (`oh-rid`)**: 3/3 LLM consensus without a primary URL is flagged as elevated hallucination risk.
4. **Evaluator Frame-Lock & Sycophantic Capitulation:**
   - *Where observed:* `Imbad0202/academic-research-skills` (31% citation error rate in v2.7 stress test), `Clebeep/academic-research-skills-claude-science-fixed`.
   - *Mechanism of failure:* A verifier or reviewer that reads the fluent draft first adopts the author's framing ("read the paper, then rationalize the standard"), and multi-reviewer synthesis buries a single reviewer's discovery of a fatal flaw under majority approval.
   - *Proven fixes:* (a) **Paper-Blind Sprint Contracts (Schema 13)** committing to rejection triggers before reading the draft; (b) **Devil's Advocate 1–5 Concession Threshold** (concede only ≥4); (c) **Sub-claim extraction (`Clebeep`)** preserving minority critical defects backed by specific evidence.
5. **Wiki Hallucination Amplification Loops (Unsourced Synthesis Poisoning Future Ingests):**
   - *Where observed:* `KevinYoung-Kw/robust-llm-wiki` (audit of 1,736-file and 1,345-file vaults), `MetamusicX/zissa-wiki`.
   - *Mechanism of failure:* When an LLM wiki ingests new sources by reading existing `wiki/` pages alongside `raw/`, any unverified inference in `wiki/` gets re-ingested as established fact.
   - *Proven fixes:* (a) **Write-time state gate (`draft` vs `stable`)** in `robust-llm-wiki`; (b) **inline epistemic provenance tags (`[W]` synthesis vs `[P]` user position vs `[?]` open question)** and deterministic quote checking (`wiki.py quotes`) in `zissa-wiki`.
