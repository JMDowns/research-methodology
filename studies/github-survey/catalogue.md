## 1. Inclusion Test, Sampling Strategy, and Stopping Rule (Q0)

Per the proposal's Q0 protocol ([`01-github-research-methods-survey-2026-11-09.md`](../research_proposals/01-github-research-methods-survey-2026-11-09.md)), we screened **72 public GitHub repositories** discovered across 6 targeted `gh search repos` and `gh search code` queries ([`sources/a-apps-and-frameworks.md`](sources/a-apps-and-frameworks.md), [`sources/b-skills-and-written-methods.md`](sources/b-skills-and-written-methods.md), [`sources/c-scientific-and-benchmark-agents.md`](sources/c-scientific-and-benchmark-agents.md)):

1. **Inclusion rule:** A repository is **Included** if its primary purpose is an explicit method, workflow, or agent architecture for conducting multi-step research with an LLM and its prompts, skills, or source code can be inspected or executed today.
2. **Stratified sampling across 4 buckets (not ranked by stars):**
   - **Type A — Research Apps & Frameworks (`A1` Recursive Tree, `A2` Hierarchical Multi-Agent, `A3` Iterative Search-Reflect-Refine, `A4` Interactive Canvas/UI):** 14 repositories inspected in full (7 scored in depth in [`scorecard-results.md`](scorecard-results.md)).
   - **Type B — Skills, Prompt Packs, Written Methods & Persistent LLM Wikis (`B1` Hybrid Skill + Python Validators, `B2` Written Multi-Agent Epistemic Contracts, `B3` Persistent Karpathy-Style `llm-wiki` Vaults):** 20 repositories included (15 inspected in full, 7 scored in depth in [`scorecard-results.md`](scorecard-results.md)).
   - **Type C — Scientific, Academic & Literature Synthesis Agents (`C`):** 6 repositories inspected in full and scored in depth in [`scorecard-results.md`](scorecard-results.md).
   - **Type D — Benchmark-Driven Long-Horizon Research Agents (`D`):** 6 repositories included (4 inspected in full and scored in depth in [`scorecard-results.md`](scorecard-results.md)).
3. **Exclusion rule:** General-purpose chat/RAG platforms (`khoj-ai/khoj`, `arc53/DocsGPT`), general agent SDKs, awesome-lists (`webfuse-com/awesome-autoresearch`, `WuizaKaseiyo/awesome-deep-research-agent`), benchmark-only evaluation harnesses without a standalone research method (`Ayanami0730/deep_research_bench`), single-purpose utility wrappers (`sankalpsthakur/omen`), and software engineering delivery plugins (`levnikolaevich/claude-code-skills`) are **Excluded** (26 repositories).
4. **Riskiest assumption & stopping rule outcome:** The Type B probe (`gh search repos` with separate keyword tokens + `gh search code --filename SKILL.md` and `--filename CLAUDE.md`) surfaced **35+ genuine Type B candidates** (20 included below), passing the $\ge 10$ threshold. Screening stopped at **72 candidates** (under the 80-repo cap) after 20 consecutive candidates added no new architectural mechanism beyond the 10 sub-families catalogued here.
